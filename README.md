# Backchannel

Backchannel is a free Android messenger with no server: every message is encrypted on your phone with the Signal Protocol and goes straight to the other phone across Tor. No account, no phone number, no adverts. Open source.

Website: https://customgpter.github.io/backchannel/

Download: https://github.com/CustomGPTer/backchannel/releases/latest/download/Backchannel.apk

Source: the code for this version is in the `android` folder, under AGPL-3.0 (see `LICENSE`). No signing key is included.
